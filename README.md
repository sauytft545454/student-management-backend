# 🚀 Student Management Backend API

## 📌 Project Overview
This is a **Student Management System Backend API** built using **Node.js, Express, and MySQL**.  
It provides RESTful APIs to manage students, departments, courses, marks, and attendance.

---

## ⚙️ Tech Stack
- Node.js
- Express.js
- MySQL
- REST API
- Git & GitHub
- Postman

---

## 🔥 Features
- ✅ CRUD operations for students
- ✅ MySQL database integration
- ✅ Multi-table relationships (7 tables)
- ✅ Advanced SQL JOIN queries
- ✅ Error handling and validation
- ✅ Tested APIs using Postman
